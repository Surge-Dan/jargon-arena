# 黑话段位局：德州牌桌与成长闭环重构规格

## 1. 产品边界

黑话段位局仍然是互联网职场文化、黑话、热梗和组织语境理解测评，不改造成“班味人格测试”，也不宣称心理或职业测量效度。

本次以德州扑克“看牌—下注—翻牌—摊牌—晋级”为交互隐喻，建立两套可独立使用、又能互相衔接的路径：

1. **快速测段位**：13–15 道自适应题，认证用户当前黑话理解水平。
2. **成长牌局**：根据测评弱项发任务牌，完成训练手牌获得筹码经验，推动成长段位升级；再次测评用于重新认证真实水平。

成长段位用于游戏化训练，不伪装成客观职业能力。离线环境无法验证真实职场行为，因此任务明确区分“题内挑战”和“线下自证任务”。

## 2. 首页与布局修复

- 根因：黄色顶线使用固定定位，但 `top` 错绑平台避让量，导致它固定横穿内容区。
- 修复：顶线使用独立 `.viewport-top-rail`，固定在 `top: 0; left: 0; right: 0`，不参与任何扫描动画或文档流。
- 全局移动安全区仍保留在应用壳和顶部导航，顶线与安全区职责拆分。
- 移除全页面往下扫的线条，避免遮挡图鉴、报告和原生控件。
- 首页中部为唯一主视觉：俯视椭圆牌桌、四名玩家剪影、发牌员、公共牌、筹码和循环发牌动画。
- 首页首屏明确展示两条路径，不把成长入口藏在测试结果后。

## 3. 德州扑克视觉系统

### 3.1 色彩

- 牌桌绿 `#0E3B2E`
- 深夜绿 `#091B16`
- 酒红 `#7A2030`
- 黄铜金 `#D2AE55`
- 象牙牌面 `#F3E8D2`
- 墨黑 `#151713`
- 铂金 `#A9D7CE`
- 钻石蓝 `#6CA9C8`

不使用蓝紫渐变、霓虹、玻璃拟态或赌场老虎机式高饱和灯效。

### 3.2 字体

- 牌桌主标题：得意黑 Smiley Sans，OFL 1.1，离线 WOFF2 子集。
- 段位判词、任务旁白：霞鹜文楷 Medium，OFL 1.1，离线 WOFF2 子集。
- 正文：系统屏幕优化黑体栈，不提取或重新分发系统字体。
- 英文与数字：Georgia / Courier New，与牌局档案和筹码编号对应。
- 中文正文 14–16px、行距 1.65–1.8；标题不合成斜体，正文不额外加字距。

### 3.3 动效

- 首页发牌：两张手牌从庄家位滑向玩家，筹码轻微推进，公共牌依次翻面。
- 答题选择：选项像下注筹码落入底池；下一题像翻牌，不做大幅页面飞入。
- 晋级：段位徽章翻面、筹码环扩散、黄铜光圈一次性亮起。
- `prefers-reduced-motion` 下关闭位移与循环，只保留状态变化。

## 4. 段位与 SVG 标识

八个等级由“金属段位 + 趣味头衔”共同组成：

1. 黑铁 · 人话萌新
2. 青铜 · 黑话观察员
3. 白银 · 热词练习生
4. 黄金 · 会议室生还者
5. 铂金 · 语境翻译官
6. 钻石 · 抓手装配师
7. 大师 · 组织语言架构师
8. 王者 · 人话掌门

每级提供独立 SVG：牌桌盾牌为统一骨架，分别使用铁砧、筹码、双牌、金冠、铂金花色、钻石、桂冠和王冠符号。SVG 作为包内本地资源，不使用远程图标库。

## 5. 测评扩充

- 题库从 44 道扩展到不少于 64 道。
- 每个五维专项支线至少 8 道，校准题至少 14 道，Boss 至少 6 道，晋级题至少 8 道。
- 新增场景：AI 汇报包装、OKR 对齐、复盘甩锅、跨部门借资源、绩效校准、降本增效、组织调整、需求优先级、群聊潜台词、会议纪要责任链。
- 仍维持单次 13–15 题，扩充的是复测变化和内容深度，不无意义拉长首次体验。
- 结果档案增加：本局牌风、常用话术、隐藏底牌、容易跟错的注、克制策略、下一级胜率缺口和三个个性化任务。

## 6. 成长牌局

### 6.1 状态模型

本地存储 `jargon-arena-growth-v1`：

- `rankId`：成长段位，1–8。
- `xp`：当前段位内筹码经验，0–99。
- `streak`：连续完成训练局数。
- `completedMissionIds`：已完成任务。
- `lastBaselineRankId`：最近一次测评认证段位。
- `unlockedAt`：各段位首次解锁时间。

首次完成测评后，成长段位至少提升到认证段位；成长训练只允许向上，不因清历史或答错而降级。

### 6.2 任务牌

- 每次展示三张任务牌，优先命中测评最低两个维度。
- 任务类型：术语破译、语境拆弹、废话过滤、人话翻译、梗文化考古。
- 题内挑战：从任务场景选择最佳回应，答对获得 35 XP，答错显示解析且可重试，首次正确才计分。
- 线下任务：给出可执行动作和完成标准，用户自证完成后获得 20 XP；明确标注“由你自行确认，工具无法验证”。
- 每 100 XP 晋升一级，多余 XP 结转；满级后转为王者筹码累计。
- 晋级后立即展示专属 SVG、段位名、解锁能力和下一段目标。

### 6.3 闭环

测评定位弱项 → 自动发三张任务牌 → 完成任务得 XP → 晋级反馈 → 解锁更难任务 → 随时重新测评 → 更新认证段位和任务优先级。

## 7. 分享正文

标题继续受 20 字限制，正文控制在 450–700 中文字符以内，包含：

- 段位与综合分开场。
- 两个专精徽章与最高/最低维度。
- 结合结果档案生成的半夸半损牌风锐评。
- 至少 8 个自然嵌入的互联网黑话或梗，不机械堆砌。
- 一段“翻译成人话”的落地总结。
- 成长任务邀请和固定话题标签。

正文根据段位、徽章、维度和任务动态生成，不再是固定三句话。

## 8. 技术模块

- `rank-assets.js`：段位元数据与 SVG 路径。
- `growth-core.js`：任务推荐、答题验证、XP 和晋级计算，纯函数优先。
- `growth-data.js`：任务牌内容。
- `storage.js`：历史和成长数据容错存储。
- `quiz-core.js` / `question-bank.js`：扩充题库与段位字段。
- `content-data.js`：扩充结果档案。
- `poster.js`：更完整的分享正文和新版牌桌通行证。
- `main.js`：快速测评、成长牌局、任务弹层和晋级反馈状态机。

保持单页、经典外置脚本、纯本地资源、无网络请求、无模块、无内联事件。

## 9. 验收

- 滚动任何页面时黄色顶线始终位于视口 `y=0`，不横穿内容。
- 320、375、430px 无横向溢出；顶部导航与小红书原生控件不冲突。
- 题库不少于 64，分支覆盖满足阈值，13–15 题无重复。
- 两条入口均可从首页直接进入；测评完成会初始化成长牌局。
- 任务推荐命中弱项，XP 结转和跨级晋升正确，同一任务不重复得分。
- 八个 SVG 均可加载；晋级动画可触发并支持减少动态偏好。
- 分享正文长度、变量插值、黑话密度和 JSBridge 参数通过测试。
- 只执行针对性单元测试、两条关键浏览器流程、三档视口和最终 ZIP 门禁。
