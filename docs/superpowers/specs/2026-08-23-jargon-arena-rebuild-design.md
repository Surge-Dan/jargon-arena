# 黑话段位局：全量重构设计规格

## 1. 产品定位

黑话段位局是一款面向互联网从业者与年轻职场人的离线互动测评。它评估用户对互联网职场文化、黑话、热梗、话术与真实语境的综合理解，并输出一个具有晋级感的“黑话段位”。

本项目不做职场人格、打工体质或心理诊断。结果仅解释用户在本次题目中的文化理解与表达倾向，不用于招聘、绩效或职业能力判断。

## 2. 核心体验目标

- 好奇：进入首页即可看到段位样例、扫描中的黑话和挑战承诺。
- 好玩：题目具有真实会议、群聊和互联网文化语境；流程含支线、关卡和晋级赛。
- 有用：结果不仅给段位，还指出用户能否识别废话并将抽象表达翻译成行动。
- 可传播：生成 1080×1440 高清“黑话通行证”，支持保存相册和发小红书笔记。
- 可复测：本地保存最近 8 次结果，展示五维变化并优先抽取未答过的题。

## 3. 完整功能清单

### 3.1 首页与导航

- 顶部统一安全区，避开系统状态栏、小红书返回键和侧边控件。
- 品牌区、动态术语扫描条、情绪向导语、测评时长与隐私说明。
- 展示三个趣味段位样例，降低首次使用的不确定性。
- 提供“开始段位测试”“段位图鉴”“黑话百科”“历史成绩”四个入口。
- 有历史记录时展示最近一次段位与继续复测入口。

### 3.2 动态分支测评

- 题库不少于 40 道，覆盖基础校准、五类专项支线、综合 Boss 与晋级赛。
- 五个连续维度：术语破译、语境雷达、梗文化考古、废话鉴别、人话翻译。
- 每个选项绑定五维权重，不采用单一对错总分。
- 8 道基础校准题后，根据维度表现选择两条专项支线。
- 每条支线抽取 2 道题，再进入综合 Boss 题。
- 段位临界或最高段位候选用户追加 1–2 道晋级赛，单次共 13–15 题。
- 复测优先选择未答过题目；同一会话不重复题目。
- 实时展示关卡阶段、已完成题数和预计剩余题数，不伪造固定总题数。
- 每题反馈包含“你刚才识别了什么”，每 4 题出现一次情绪化关卡提示。
- 防止重复点击、重复记分、空答案和异常分支死循环。

### 3.3 计分与段位

- 各维度按本次所答题目的可得权重归一化为 0–100。
- 综合分为五维等权平均，避免某类题目数量更多导致偏置。
- 八级段位：人话保护区原住民、黑话村口观察员、热词练习生、会议室生还者、语境翻译官、抓手装配师、组织语言架构师、返璞归真人话掌门。
- 最高段位设置双门槛：综合分达标且废话鉴别、人话翻译均达到要求。
- 依据最高维度生成两个专精徽章，例如热梗活化石、会议拆弹员、废话过滤器、人话同传、责任定位器、新词雷达站。
- 段位报告使用半夸半损的文案，带晋级感但不使用青铜/白银换皮。

### 3.4 结构化报告

- 黑话通行证头图：段位、综合分、专精徽章、档案编号、专属锐评。
- 五维雷达图和逐维分数条。
- 报告板块：段位画像、你的高光、容易翻车的场面、会议现场表现、人话处方、下一级晋级任务。
- 显示本次答题路径与命中的专项支线，增强结果可信度。
- 明确娱乐与自我观察边界，不声称心理测量效度或人群百分位。

### 3.5 段位图鉴

- 浏览全部八个段位，不设置付费或分享解锁。
- 每个段位包含一句话画像、典型表现、常见翻车点和晋级建议。
- 当前段位高亮，并显示距离下一段位的提升方向。

### 3.6 黑话百科

- 内置不少于 30 个互联网职场词条。
- 分类包括项目推进、组织管理、汇报包装、绩效协作和网络文化。
- 每个词条提供：字面包装、人话翻译、使用风险、建议追问。
- 支持本地关键词搜索和分类筛选，无联网请求。

### 3.7 历史记录与复测

- 使用 localStorage 保存最近 8 次结果，只保存在当前小工具本地空间。
- 记录时间、段位、综合分、五维分数、专精徽章和题目 ID。
- 当前结果与上一次结果做五维增减对比。
- 支持查看历史详情、以旧结果生成分享图、再次测评和自定义确认弹窗清空记录。
- 存储不可用或数据损坏时自动降级为无历史模式，不阻断测试。

### 3.8 高清分享

- Canvas 生成 1080×1440 PNG，包含段位、雷达图、徽章、锐评与话题标签。
- 小红书容器内优先调用 `writeTempFile` 与 `saveImageToPhotosAlbum` 保存相册。
- 提供“发小红书”入口，调用 `postNote` 并预填标题、正文、标签和分享图。
- 普通浏览器中显示高清图片预览，提示右键/系统菜单保存；不使用被容器禁用的 `a[download]`。
- 导出失败时保留预览并显示明确的恢复指引。

### 3.9 通用体验与异常处理

- 首页、答题、报告、图鉴、百科、历史、弹窗与分享预览统一安全区。
- 主要按钮最小触控高度 48px，移动端左右留出原生控件避让空间。
- 320px、375px、430px 宽度均无横向溢出；短屏支持自然滚动。
- 支持键盘焦点、方向键选择、ARIA 状态、减少动态效果偏好。
- 题库、分支和结果数据启动校验；异常时显示可恢复错误页。

## 4. 视觉系统

### 4.1 方向

“职场文艺 × 轻电子扫描仪”。视觉来源是复印件、工牌、会议批注、打孔纸、旧式终端扫描条，而不是通用科技产品。

### 4.2 色彩

- 夜班墨 `#222421`：主背景。
- 复印纸 `#E8E1D3`：报告与正文底色。
- 档案灰 `#9A9B91`：辅助信息。
- 工牌黄 `#D3B75A`：进度与主操作。
- 批注红 `#C85B45`：风险、盖章和重点。
- 扫描青 `#78A69C`：电子扫描状态，低饱和使用。

### 4.3 字体与布局

- 大标题使用系统宋体/仿宋回退，形成文艺编辑感。
- 正文使用系统无衬线字体，保证移动端可读性。
- 数据与编号使用等宽字体。
- 页面以纵向档案流为主，减少圆角卡片；用编号、装订线、盖章与批注建立层级。
- 唯一高辨识度动效为“术语扫描线”：用于首页、答题切换和报告生成，其他动效保持克制。

## 5. 技术结构

- `quiz-core.js`：题库校验、动态路径、五维归一化、段位和徽章。
- `question-bank.js`：40+ 道题与分支元数据。
- `content-data.js`：段位档案、词典、提示与报告文案。
- `storage.js`：历史记录容错与复测去重数据。
- `poster.js`：雷达图和 1080×1440 分享图、JSBridge 保存/发布。
- `main.js`：单页状态机、DOM 渲染和交互。
- 所有脚本均为经典外置脚本，无模块、网络请求和第三方依赖。

## 6. 验收标准

- 分支路径可复现、无重复题、总题数 13–15，临界晋级赛触发正确。
- 五维归一化、段位双门槛、徽章排序和历史对比均有单元测试。
- 题库数量、ID、维度权重、分支覆盖和内容完整性通过启动校验。
- 首页到结果、图鉴、百科、历史、复测、分享预览和 Native API 降级均通过 Playwright。
- 320×568、375×812、430×932 页面无遮挡、无横向溢出，顶部安全区不小于容器变量与设计余量之和。
- 生成分享图为 1080×1440 PNG。
- 最终 ZIP 根目录含 `index.html`，原始条目使用 `/`，无外部资源、禁用 API 和非法路径，上传前门禁通过。
