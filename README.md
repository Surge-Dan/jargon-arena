# Jargon Arena

中文名：**黑话段位局**

一个离线运行的互联网黑话段位测试小工具。用 10 道场景题，测测你能不能把职场黑话、网络梗和抽象表达翻译成人话。

## 功能

- 10 道互联网黑话与网络语境选择题
- 覆盖会议求生、热梗识别、语境判断和人话翻译
- 即时反馈与进度提示
- 6 档测试结果，从“黑话村口观察员”到“互联网黑话宗师”
- 结果标签与逐题解析
- 支持重新测试
- 全程本地运行，不上传答题记录

## 设计方向

产品采用暖黑、米白和土黄色的纸张记录感视觉，模拟一份带有批注的“黑话研究档案”。界面避免蓝紫渐变、霓虹光效和模板化 AI 视觉，适合在移动端快速完成并截图分享。

## 技术特点

- 原生 HTML、CSS 和 JavaScript
- 无框架、无构建步骤、无第三方依赖
- 无外部网络请求，可离线运行
- 移动端优先，适配小红书小工具容器
- 题库、评分逻辑和界面逻辑分离，便于后续扩充题目

## 本地运行

项目是纯静态页面，可以直接用浏览器打开 `index.html`。如果需要通过本地服务器预览：

```bash
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 发布到小红书小工具

将仓库根目录中的 `index.html` 和 `assets` 文件夹一起打包为 ZIP，确保 `index.html` 位于压缩包根目录，再按照小红书 Builder Hub 的小工具上传流程进行预览和提交。

## 项目定位

这是一个以娱乐和社交分享为主的轻量测试工具，测试结果仅供娱乐，不代表真实职业能力。
